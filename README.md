# 🎯 Number Guessing Game

A simple Python implementation of the **Number Guessing Game** where the computer picks a random number between **1 and 100**, and you have to guess it.

## Features

* Computer generates a random number between 1–100
* Gives hints (**Higher / Lower**) after each guess
* Tracks the number of attempts
* Beginner-friendly and easy to run

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/Mani-doliya/Number-Guessing-Game.git
```

2. Run the game:

```bash
python game.py
```

3. Enter your guesses until you find the correct number.

Example:

```
Guess the number: 50
Higher number Please
Guess the number: 75
Lower number please
Guess the number: 63
You have guessed the number 63 correctly in 3 attempts
```
